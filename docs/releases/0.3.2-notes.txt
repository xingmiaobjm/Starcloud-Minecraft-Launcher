0.3.2
· 新增「运行状态」页：当前这局游戏收在一处 —— CPU / 内存曲线、生效的 Java 与 JVM 参数、实时日志尾、最近运行记录，并支持在页内结束进程。
· 账户界面重构成「列表 + 二级页」：添加账户与账户详情各成一页，皮肤库、会话状态、首选设置都在页内完成，不再连弹窗。
· 皮肤库：离线账户可导入本地皮肤或链接、随时切换；第三方账户直接列出皮肤站衣柜；头像与卡片走同一条光栅化路径。
· 插件 SDK 全面开放：版本 / 实例 / 下载 / 网络 / 设置 / 任务 / 存档 / 联机等能力对插件开放，JS 与 Python 能力面对齐；随附规范与 SDK 指南更新，同时恢复离线登录。
· 账户语义改名：账户卡的「默认账户」统一改为「首选账户」（用于一键启动），界面文案与提示同步。
· 主页版本卡改版：收起后成为底部窄条，与右侧启动区底边对齐；两栏上边缘错位一并修掉。
· 视图层按职责下沉（控件 / 行为 / 对话框 / 覆盖层 / 行 / 共享），按钮统一收敛到 GlowButton，悬停阴影与动效口径随之对齐。
