0.3.11

新增
· 高级传递优化。下载时与全网用户互相加速：利用闲置带宽为其他用户提供文件，也能从其他在线用户获取相同文件。服务器只负责撮合，不参与文件传输；全程按官方指纹校验，校验不过自动回退官方下载。可在设置中限制上传速度或整体关闭。
· 云端公告。启动器接收并展示官方公告，支持排版与链接，公告内容仅作展示。
· Java 运行时多发行版下载。设置页 Java 区新增发行版选择（Temurin / 龙井 Dragonwell），并列出各发行版的全部可用版本；当其中一个来源无法访问时，可切换另一个。
· 首次启动使用引导。介绍各页面功能，并引导完成 Starcloud ID 登录、游戏账户创建与游戏目录导入，跳过后随时可在设置中补上。
· 任务栏图标跟随系统深浅色自动切换。
· 安装程序自动在所选目录内新建 Starcloud 子文件夹，不再把文件铺进用户选择的目录本身。

优化
· CurseForge 整合包导入提速：文件解析改为批量接口，数百个文件的解析从数分钟缩短到数秒。
· Modrinth 整合包导入更稳：自动跳过服务端专属文件；主地址失败时按包内备选地址自动补拉。
· 整合包识别增强：支持外层再包一层压缩包的嵌套形态；仅含 kubejs 脚本或服务器配置的整合包也能识别导入。
· 皮肤站衣柜改进：兼容 Blessing Skin 4 接口形态；衣柜超 100 张时完整拉取；卡片先展示、缩略图并行加载；多账户之间不再串显。
· 存档、下载等内容页的条目改为逐条羽化滑入，页面骨架先行渲染。
· 安装程序打开耗时由约 13 秒缩短至 1 秒左右。
· 更新弹窗与公告弹窗统一为新的视觉样式，小窗口下不再溢出。

调整
· 「跨设备与 P2P」设置区更名为传递优化 / 高级传递优化 / 最大上传速度，并移除通道状态行。
· 首页移除启动自检卡片。
· 控件圆角由 12 调整为 8。
· 移除启动提示中关于自检的文案。

修复
· 修复微软登录在浏览器关窗瞬间丢失授权、表现为登录成功但未登录的问题。
· 修复导入整合包后版本列表多出「原版 / 加载器」条目的问题：联动安装的依赖版本不再单列，已有列表也会自动收敛。
· 修复部分 Mod 简介不显示中文翻译的问题（翻译接口改版适配，并改为整页批量请求）。
· 修复开启传递优化后批量下载被逐条查询拖慢的问题。
· 修复未登录时开启高级传递优化，开关状态与实际运行状态不一致的问题。
· 更新清单新增签名校验与强制完整性检查：清单或安装包被篡改时将拒绝更新；发布产物随包附带签名文件。

安全加固
· 更新过程不再保留任何跳过验签的路径：仅本机调试用的免验签逻辑改为编译期开关，发布版二进制里没有这段代码。
· 更新清单与安装包地址仅接受 https，只有本机调试构建才额外放行 http，避免更新被降级为明文传输。
