0.4.0 Beta
· 注册改为邮箱验证码两步式：账户页「没有账号？注册」打开独立小窗，填 ID / 邮箱 / 验证码 / 密码即可完成注册，验证码按钮带 60 秒倒计时。注册成功后自动回填 ID，直接登录。
· 首页账户卡精简：去掉「类型 / UUID / 皮肤」三行明细，卡片只保留头像、账户名与启动按钮。
· 「切换账号」改为悬停显示：平时隐藏，鼠标移到账户名下方才浮现，卡片更干净。
· 手机版 WebView 窄屏适配：竖屏下导航与页面排版随宽度重排，不再横向溢出。
· 设置页开关去掉默认的「关 / On / Off」文字，只保留开关本身。
· 下载页「已安装」徽标与版本名脱开，长版本名不再挤压徽标。
· 投影管理页未选中投影时给出操作引导；投影预览就绪握手修复。
