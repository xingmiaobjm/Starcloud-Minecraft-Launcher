# Starcloud Windows 端视觉规范（供 Linux 端实现对齐）

> 版本：2026-10-20　对应 Windows 端 0.3.4
> 适用：Linux / Flutter 端（以及任何需要与 Windows 端保持同一视觉语言的端口）
> 事实来源：`dotnet/src/Starcloud.App/App.xaml`（设计令牌）、`MainWindow.xaml`（外壳）、
> `Views/*.xaml`（页面）、`Services/MotionService.cs`（动效分级）、
> `docs/designs/2026-09-21-brand-mark-design.md`（品牌标记）、`Assets/Brand/`（图标源文件）。
>
> 本文只描述 **视觉与交互语言**，不含业务逻辑。所有数值都是 Windows 端正在使用的值，
> 标 ★ 的是「照抄即可」的硬令牌，标 ○ 的是「可以按平台习惯微调、但必须保持同一观感」的建议值。

---

## 1. 一句话风格

**近白 / 近黑的低饱和底 + 一个高亮品牌黄 + 大圆角玻璃卡片 + 极轻的指针跟手光效。**

界面本身几乎没有彩色：除了品牌黄、语义色（成功/危险/警告）和 Nova 的紫色，
其余全部是中性灰阶。彩色只出现在"需要被点的地方"和"状态"上。

对标：Windows 11 Fluent 的排版与动效节奏 + 自家品牌的黄色强调。**不要**做成游戏启动器常见的
深色霓虹风，也不要 Material 的高饱和色块。

---

## 2. 设计原则

1. **一个强调色**：品牌黄 `#FFD322`。同一屏里不要出现第二个高饱和色块（Nova 紫是唯一例外，
   且只在 Nova 相关区域）。
2. **黄色面上必须是黑字**：品牌黄亮度高，白字对比度只有约 1.4:1。所有 accent 背景都用 `#1A1A1A` 系文字。
3. **克制**：动效只表达状态变化，时长 120–250ms；不做弹跳装饰、不做持续呼吸。
4. **可降级**：任何动效/毛玻璃/光影失败都要静默退化为静态，功能不受影响。
5. **尊重系统**：系统关闭动画时全部动效关闭（含页面转场）。
6. **层次靠明度，不靠线条**：卡片与底之间优先用 1px 极浅描边 + 极淡阴影，不用重投影。

## 3. 色彩

### 3.1 品牌色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| Accent / 品牌黄 ★ | `#FFD322` | 主按钮底、选中态、焦点环、进度条、品牌图形 |
| Accent 悬停 ★ | `#FFBC00` | 主按钮 hover；也是"按下"的深一档 |
| Accent 按下 ★ | `#E6A800` | 主按钮 pressed |
| Accent 禁用 ★ | `#99FFD322`（60% 透明） | 禁用主按钮 |
| Accent 浅一档 ★ | `#FFDD4D` / `#FFE780` / `#FFF0B3` | 需要三阶浅色时用 |
| Accent 深一档 ★ | `#FFBC00` / `#D9A000` / `#B38500` | 浅色底上的黄字用 `#B38500` 保证对比度 |

> 浅色主题上"黄色文字"不能用 `#FFD322`（对比不足），要用 `#B38500`；
> 深色主题上反过来直接用 `#FFD322`。

### 3.2 中性色（两个主题）

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 正文主文字 ★ | `#1A1A1A` | `#F5F5F5` |
| 次要文字 ★ | `#666666` | `#A0A0A0` |
| 三级文字 ★ | `#666666` @ 60% | `#A0A0A0` @ 53% |
| 禁用文字 ★ | `#666666` @ 36% | `#A0A0A0` @ 34% |
| 卡片描边 ★ | `#E2E2E2` | 用 8% 白（`#14FFFFFF`） |
| 侧栏 / 标题栏实色底 ★ | `#F6F6F6` | `#161616` |
| 内容区底 ○ | 跟随背景（半透明层，让壁纸透出） | 同左 |

- 窗口内容区**不要**铺不透明实色：Windows 端内容区是半透明层 + 窗口亚克力，自定义背景图能透出来。
- 侧栏和标题栏是**不透明实色**（`#F6F6F6` / `#161616`），与内容区形成一条清晰的明度分界，
  但**不加分割线**（模板自带的 1px 描边要主动去掉，否则交界处会出现黑色拼接缝）。

### 3.3 语义色

| 语义 | 值 | 用途 |
| --- | --- | --- |
| 成功 ★ | `#3DDC84` | 完成、已就绪、安装成功 |
| 危险 ★ | `#F44336` | 删除、失败、崩溃 |
| 警告芯片 底/字（浅） ★ | `#1FF59E0B` / `#B45309` | 提示条、注意项 |
| 警告芯片 底/字（深） ★ | `#2EF59E0B` / `#FBBF24` | 同上 |

### 3.4 Nova（AI 助手）专属色

只在 Nova 头像、Orb、状态点、Nova 页使用，**不要外溢到其它页面**。

| 状态 | 值 |
| --- | --- |
| 空闲 ★ | `#71717A` |
| 思考中 ★ | `#7C3AED`（nebula 紫） |
| 规划中 ★ | `#F59E0B` |
| 观察中 ★ | `#10B981` |
| Orb（深色主题） ★ | `#A78BFA` |

### 3.5 透明度约定

- 悬停底 / 选中底：黑 4%（浅色 `#0A000000`）、黑 22%（深色 `#38000000`）。
  两个主题都必须是"压暗"，不要用"加白"——否则在深色卡片上会变成一块白框。
- 图标按钮的透明底：`Background=Transparent`，悬停时用 4% 黑 / 白叠加。

## 4. 字体与排版

### 4.1 字体 ★

- 中文 / 界面主字体：**HarmonyOS Sans SC**
- 字重：全局 **Medium（500）**。这个家族本机只装了 Medium/Bold/Black，没有 Regular；
  正文、标题一律 Medium，避免整屏发虚。
- 只有"选中 / 未选中"这类靠字重表达状态的地方，选中时提到 **Bold（700）**。
- 数字与英文不单独换字体（HarmonyOS Sans SC 自带拉丁字形），只有品牌字标用几何无衬线。

> Flutter 落地：把 HarmonyOS Sans SC 的 ttf 打进 assets，`fontFamily: 'HarmonyOS Sans SC'`，
> `fontWeight: w500` 作为默认。缺字体时回退到系统无衬线（Noto Sans CJK SC）。

### 4.2 字号阶梯 ★

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 页面主标题 | 28–30 | Medium |
| 大数字 / 区块标题 | 22–24 | Medium |
| 卡片标题 / 列表主行 | 17–18 | Medium |
| 正文 / 控件文字 / 导航项 | 14 | Medium |
| 次要说明 | 12–13 | Medium |
| 辅助标注（时间、版本号） | 11 | Medium |
| 微型徽标 | 9–10 | Medium |

页面主标题统一 28（个别落地页用 30），**不要**出现 26 / 27 这种离群值。

### 4.3 行高与截断 ○

- 正文行高 1.5–1.6；标题 1.25。
- 单行列表主文字用尾部省略号；两行描述用 2 行截断 + 省略号，不做展开箭头。
- 数字与英文不强制等宽（除日志、路径、哈希用等宽字体）。

## 5. 图标

### 5.1 图标体系

Windows 端有**两套**图标，职责不同：

1. **功能图标 = 字体图标**（HarmonyOS Icons，MIT，字形取自 HarmonyOS Design）
   - 字体文件：`Assets/Fonts/HarmonyOSIcons.ttf`，家族名 `harmonyos`
   - 用法：`FontIcon` + 字形码点（如 `&#xE99A;`），**逐元素指定字体**，不做全局隐式替换
   - 颜色：跟随文字色；强调态用品牌黄
2. **品牌图形 = SVG**（`Assets/Brand/`）
   - `starcloud-mark-light.svg` / `starcloud-mark-dark.svg`：主标记（浅色描边 `#111418`，深色描边 `#E6EAF2`，黄色面 + 星）
   - `starcloud-mark-small.svg`：16–24px 单块简化标记
   - `lab-nav*.svg`、`projection-nav*.svg`、`devices-nav*.svg`：自定义导航图标，**每个都有 light/dark 两份**

> Flutter 落地：功能图标用 `Icons`/自定义 icon font（可直接用同一份 HarmonyOSIcons.ttf）；
> 品牌 SVG 用 `flutter_svg`，按主题切换文件名后缀。

### 5.2 尺寸阶梯 ★

| 场景 | 尺寸 |
| --- | --- |
| 导航项图标 | 20 |
| 按钮内图标 | 16 |
| 顶栏图标按钮（Nova / 任务中心 / 账户） | 32 容器内 15–16 |
| 品牌标记（标题栏） | 22 |
| 品牌小标记（导航、列表前置） | 15 |
| 空状态大图标 | 40–48 |
| 背景装饰 / 图标水印 | 64+ |

- 图标永远是**正方形容器**，视觉重心居中；同一行内图标尺寸必须一致。
- 描边风格图标（品牌 SVG）线宽按 400 单位基准 9 设计，缩到 22px 时约 0.5px，
  所以**不要**把品牌描边图标缩小到 16px 以下——低于 32px 用 `starcloud-mark-small.svg`。
- **不要**用 emoji 代替功能图标（平台渲染差异大，且与字体图标风格冲突）。

### 5.3 主题切换

品牌 SVG 与自绘导航图标都是**两份文件**（light/dark），在 `ActualThemeChanged` 时换源，
不在运行时给 SVG 上色。功能字体图标则直接继承前景色，不需要两份。

## 6. 形状

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 控件圆角 ★ | 12 | 按钮、输入框、下拉、路径条 |
| 卡片圆角 ★ | 20 | 内容卡片、封面卡、分组容器 |
| 弹出层圆角 ★ | 16 | 对话框、浮层、提示条 |
| 小元素圆角 ○ | 8 | 窗口控制按钮底、徽标底、小图标底 |
| 胶囊 | 999 | 版本芯片、状态胶囊 |

规则：

- **同一元素的内外圆角必须联动**：卡片内嵌按钮/图片时，内层圆角 = 外层圆角 − 内边距
  （例：20 的卡片 + 8 内边距 → 内层 12）。不要手写魔数。
- 焦点环也是圆角矩形，半径与控件一致。
- 圆角不要出现 6 / 9 / 10 / 3.5 这类离群值（历史遗留，新代码一律取上表）。

### 7.1 窗口

| 项 | 值 |
| --- | --- |
| 标题栏高度 ★ | 48 |
| 窗口控制按钮 ★ | 40×40，圆角 8，图标 10 |
| 左侧导航（收起） ★ | 48（仅图标） |
| 左侧导航（展开） ★ | 232 |
| 最小窗口尺寸 ○ | 960×640 |
| 页面内容最大宽度 ★ | 1280，居中 |

- 标题栏左侧：品牌标记 22 + 产品名；右侧：Nova Orb、任务中心、账户、最小化/最大化/关闭。
- 标题栏与内容区之间**不加分割线**。
- 窗口控制按钮悬停时才出现 8% 白的圆角底；关闭按钮悬停用危险色底。

### 7.2 页面骨架

```
┌ 标题栏 48 ────────────────────────────────┐
│ 标记 产品名            Nova 任务 账户  －□× │
├ 侧栏 48/232 ┬ 内容区（MaxWidth 1280，居中） ┤
│  导航项      │  页面标题 28                  │
│  …          │  副标题 12–13 次要色           │
│             │  卡片组（间距 12–16）           │
└─────────────┴──────────────────────────────┘
```

- 内容区左右内边距：24（窄窗口）/ 32（宽窗口）；上下 20–24。
- 页面标题与第一组卡片之间 16–20。
- 卡片之间的间距 **12–16**；同一组内 12，跨组 20–24。
- 卡片内边距：**16**（紧凑 12，大卡 20）。
- 列表行高：单行 48–56，双行 64–72。

### 7.3 间距阶梯 ○

`4 / 8 / 12 / 16 / 20 / 24 / 32`。不要用 5 / 7 / 11 / 15 这类值。

## 8. 组件规范

### 8.1 按钮（三型）

| 型 | 底 | 字 | 用途 |
| --- | --- | --- | --- |
| 主按钮 | 品牌黄 `#FFD322`，hover `#FFBC00`，pressed `#E6A800` | `#1A1A1A` 90% | 每屏最多一个：安装 / 启动 / 保存 |
| 次按钮 | 透明或 4% 中性底，1px 描边 | 主文字色 | 取消 / 次要操作 |
| 图标按钮 | 透明，hover 4% 中性底 | 次要文字色 | 顶栏、卡片右上角 |

- 高度：32（紧凑）/ 40（标准）；主按钮在落地页可以更大（48–64）。
- 内边距：横向 16，纵向 8。图标 + 文字时图标与文字间距 8，图标 16。
- 圆角 12。**不要**用全胶囊按钮（除芯片）。
- 悬停反馈：底色变化（83ms 过渡）+ 极轻上浮/阴影，不要缩放超过 1%。
- 禁用：整体 60% 透明，不改变色相。

### 8.2 卡片

- 底：玻璃卡片（浅色：白 72% tint + 模糊；深色：`#2B2B2B` 75% tint），效果不可用时退化为
  近实色（浅 `#F9F9F9` / 深 `#1F1F1F`）。
- 描边 1px：浅 `#E2E2E2`；深 8% 白。
- 圆角 20，内边距 16。
- 阴影：**极淡**。浅色 `#06000000` 外 + `#0C000000` 内两层同心；深色 `#16000000` / `#24000000`。
  阴影只在指针靠近/悬停时从边缘露出一弯，常态几乎不可见。
- 卡片可点击时：hover 叠 4% 中性底（不要整块换色），pressed 再深一档。

### 8.3 列表行

- 行底：透明；hover / 选中叠"压暗层"（浅 `#0A000000`，深 `#38000000`）。
- 选中态**不加左侧色条**，用压暗底 + 文字色提亮表达。
- 行内结构：前置图标 20 / 封面 40×40 圆角 8 / 主文字 14 / 次文字 12 / 右侧操作按钮。

### 8.4 输入与选择

- 输入框：高 32–36，圆角 12，底 4% 中性，聚焦时底变实 + 1px 品牌黄描边。
- 下拉 / 开关 / 单选 / 复选：沿用平台控件，但字体统一、字重 Medium。
- 开关开启态用品牌黄。

### 8.5 空状态 ★

统一一个组件，四件套：

```
[图标 40–48，次要色]
标题 16–17 Medium
副标题 12–13 次要色，最多两行
[可选] 一个次按钮（"去下载" / "刷新"）
```

- 居中，垂直方向在可用区域内偏上 1/3。
- 不要用"错误/警告"图标表达"还没有内容"。
- 不要出现纯文字空状态或空白页。

### 8.6 对话框

- 圆角 16，底为实色（不用亚克力），宽度 400–520。
- 标题 20 Medium；正文 13 次要色；底部按钮右对齐：次按钮在左、主按钮在右。
- 遮罩：黑 40%，不做模糊。

### 8.7 提示条（页面级浮层）

- 从页面顶部滑入，圆角 12，底用语义色的 12% 透明 + 同色文字，1px 同色 25% 描边。
- 自动消失 3s；同一时刻只显示一条，新的顶掉旧的。

### 8.8 进度

- 线性进度条：高 4–6，圆角全满，轨道 8% 中性，填充品牌黄。
- 环形进度：直径 20–32，线宽 2–3，品牌黄。
- 安装/下载这类长任务必须给**确定性进度**（百分比或至少"已下载/总量"），不要只转圈。

## 9. 动效

### 9.1 四档（用户可在设置里切换，默认"均衡"）★

| 档位 | 键 | 内容 |
| --- | --- | --- |
| 极少 | `minimal` | 只有页面切换转场 |
| 较少 | `lite` | + 跟手光斑、毛玻璃卡片、悬停/入场微反馈 |
| 均衡 | `balanced` | + 全局实时鼠标光照、按钮阴影跟随鼠标、边缘引力形变（**默认**） |
| 全部 | `full` | + 弹簧形变、窗口环境光斑（高性能独显推荐） |

系统"显示动画"关闭时，**所有动效统一抑制**（含转场）。

### 9.2 时长与曲线 ○

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 悬停 / 按下换色 | 83ms | ease-out |
| 页面转场（进入） | 200–250ms | 淡入 + 上移 8–12px |
| 浮层 / 提示条 | 150–200ms | ease-out |
| 进度条填充 | 200ms | ease-out |
| 展开 / 收起 | 200ms | ease-in-out |

- 单次动效不超过 250ms。
- 不做弹跳（`elastic`/`bounce`），除非在"全部"档的弹簧形变里。

### 9.3 指针光效（Windows 端特色，Linux 可选实现）

"均衡"档及以上：

- **边缘光**：1px 内描边，径向渐变亮核跟随光标，最高 50% 不透明度。
- **阴影跟随**：光标在左，阴影往右偏移一点（2–4px），像按钮被光"推"了一下。
- **引力形变**：卡片/按钮朝光标方向轻微拉伸（≤2%）。

"较少"档：以上全部静态化（固定边缘光 + 固定落影），不跟手。
"极少"档：全部关闭。

> 如果 Linux 端不做指针光效，请至少保留 **悬停换色 + 轻微上浮 + 极淡阴影**，
> 这是这套视觉的"手感基线"。

## 10. 主题与背景

- 支持浅色 / 深色 / 跟随系统三态；切换即时生效，不需要重启。
- 支持自定义窗口背景（图片/纯色/渐变），内容区半透明以透出背景；侧栏与标题栏保持实色。
- 背景上叠一层随主题变化的遮罩：浅色用白 60–70%，深色用黑 50–60%，保证文字对比度。
- 毛玻璃卡片必须提供 **fallback 实色**（效果不可用时自动退化）。

---

## 11. 无障碍

- 焦点环：2px，浅色 `#B38500`，深色 `#FFD322`，**只有一圈**（不要黑白双环）。
- 最小点击区域：32×32（图标按钮）；主要操作 40 高。
- 正文对比度 ≥ 4.5:1；黄色底上的黑字约 12:1。
- 所有图标按钮必须有可读名称（tooltip / a11y label）。
- 系统减少动效时遵守（见 §9.1）。

## 12. 落地对照表（WinUI → Flutter 建议）
