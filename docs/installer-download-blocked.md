# 安装包被浏览器/杀毒软件拦截的说明与处理

日期：2026-10-23
适用：`Starcloud Minecraft Launcher_*_x64-setup-*.exe`（NSIS 安装器）与 portable zip

## 1. 结论先行

文件本身没有问题：Windows Defender 对发布产物实扫无威胁（`MpCmdRun -Scan` 复核过）。
浏览器与杀毒软件的拦截属于**下载信誉类拦截 / 误报**，根源是三点：

1. 安装包**没有代码签名**，无法向系统证明发布者身份；
2. 新发布的文件**下载量为零**，SmartScreen 与杀软云查杀的信誉库中没有记录；
3. NSIS 定制界面安装器长期是恶意软件的重灾区，杀软对这一形态普遍敏感。

## 2. 用户侧放行（当前版本的临时做法）

| 拦截方 | 现象 | 放行方式 |
|---|---|---|
| Edge / Chrome | 下载条提示「可能有害 / 已阻止」 | 点下载项 `…` → **保留**；Edge 再点「显示详情 → 仍然保留」 |
| SmartScreen（双击运行时） | 蓝色「Windows 已保护你的电脑」 | 点「更多信息」→「**仍要运行**」 |
| Windows Defender | 下载后文件被隔离 | 「保护历史记录」→ 恢复并加入允许列表 |
| 360 / 腾讯管家 / 火绒 | 报「风险程序 / 未知的程序」 | 恢复文件 → 添加信任目录；或在防护记录里标记「信任此文件」 |

下载页应展示安装包的 SHA256（`latest.json` 已包含），供用户核对放行的是原始文件。

## 3. 根治路径（按优先级）

1. **代码签名证书**（唯一根治手段）：
   - OV（组织验证）：解除「未知发布者」，SmartScreen 信誉随下载量逐步累积，通常数百元/年起；
   - EV（扩展验证）：签发后立即继承 SmartScreen 信誉，基本不再出现下载拦截，数千元/年起；
   - Azure Trusted Signing（微软官方签名服务）：按月计费、门槛低，个人/小团队可行，值得优先评估（注意服务区域与身份验证要求）。
2. **误报申诉**（无证书期间的补救，1–5 个工作日生效）：
   - 微软：`microsoft.com/wdsi/filesubmission`（提交后 Defender 云查杀放行）；
   - 360：`open.soft.360.cn`；腾讯管家：`avhub.tencent.com`；火绒：官网「误报提交」。
   - 注意：**每次重新打包哈希都会变化**，申诉结果不可继承。因此发版窗口内尽量固定一个安装包文件，不要反复重打包。
3. **分发渠道调整**：
   - 浏览器对**裸 exe 下载**拦截最狠，对 **zip 压缩包**宽松得多——对外下载页建议优先提供 portable zip，安装器 zip 化后再提供（解压后 Defender 实扫本文件是干净的，不会拦）；
   - 域名信誉也有影响：starcloudfur.cn 是新域名，直接从官网挂裸 exe 会加重拦截，挂 zip + 展示 SHA256 是稳妥形态；
   - 启动器**应用内自更新**不走浏览器，只受 Defender 实时防护影响（本文件实扫干净），这条链路不受下载信誉问题困扰。

## 4. 安装器已做的信誉优化

- `RequestExecutionLevel user`：声明按用户级运行（本产品只装 `%LOCALAPPDATA%\Programs\Starcloud`、只写 HKCU，无需管理员），避免触发 UAC「安装程序检测」启发式；
- `VIAddVersionKey OriginalFilename "Starcloud Minecraft Launcher Setup.exe"`：杀软会核对版本信息与分发名的一致性，缺失属于减分项；
- `CRCCheck off` 与 NSIS 常规行为差异不影响查杀判定，无需回退。

## 5. 一句话给用户

下载被拦不是文件有病毒，是「没签名的安装包 + 零下载记录」的默认待遇。短期按 §2 放行，中期接签名证书（§3.1），同时把 SHA256 挂在下载页（§3.2）。
