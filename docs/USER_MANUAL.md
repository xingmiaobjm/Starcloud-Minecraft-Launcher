# USER_MANUAL.md — Starcloud 启动器用户手册（WinUI 3 版）

> 适用于 .NET / WinUI 3 版本（`dotnet/`）。旧 Tauri 版手册已随旧架构弃用。

## 1. 系统要求

- Windows 10 1809（build 17763）或更高，仅 x64
- 无需安装 WebView2 或其他运行库——应用为自包含发布（SelfContained）
- 首次启动游戏需要 Java（可由启动器托管下载，见 §4）

## 2. 界面总览

左侧为常驻导航栏（与 Microsoft Store 一致），右侧为内容区：

| 导航项 | 功能 |
| --- | --- |
| 首页 | 启动面板：选账户、选版本、启动游戏 |
| 下载 | 浏览官方版本清单并安装 |
| 模组资源 | 安装 Fabric 加载器 |
| 账户 | 管理离线账户与微软正版账户 |
| 设置 | 游戏目录、内存、Java、下载与外观 |
| 启动器日志（底部） | 查看启动器运行日志 |

界面跟随系统深浅色与系统强调色；可在设置中改为固定浅色/深色。

## 3. 首次使用（三步）

1. **安装版本**：进入「下载」页，选择一个正式版（如 1.21.x）点击安装，等待进度完成
2. **配置账户**：进入「账户」页添加离线账户（或微软登录）；回到首页在左侧选择账户
3. **启动游戏**：首页左侧选择版本 → 点击「启动游戏」大按钮

首次启动时右侧会显示新手引导卡片，三步完成后自动隐藏。

## 4. 首页

左侧为启动面板（卡片）：

- **账户模式**：「正版 / 离线」双切换按钮
  - 正版：从已登录的微软账户中选择
  - 离线：直接输入玩家名（同时可在下拉中切换历史离线账户）
- **头像与账户名**：圆形头像显示玩家名首字符
- **账户下拉框**：切换账户
- **版本下拉框**：切换已安装版本；下方显示版本元信息
- **启动游戏**（大按钮，双行）：主行为「启动游戏」+ 当前版本号；启动中显示状态
- **选择版本 / 版本管理**：快捷跳转到下载页 / 管理已安装版本
- **进度条**：安装或下载任务进行时显示

右侧为欢迎语、错误/警告提示条（InfoBar）与三个快捷入口卡片
（下载版本 / 模组资源 / 好友联机——联机功能规划中）。

## 5. 下载页

- 列表来自 Mojang 官方版本清单（本地缓存优先，秒开）
- 按类型筛选：正式版 / 快照 / 旧版等
- 每行显示版本号、类型、发布时间与「已安装」标记
- 点击安装 → 显示下载阶段（游戏文件 / 本地库 / 资源）、进度百分比与速度
- 安装内容：客户端 jar、全部依赖库、windows natives、全量资源文件（SHA1 校验）

## 6. 模组资源页

安装 Fabric 加载器：

1. 选择 Minecraft 版本（需已安装原版）
2. 加载器版本默认取最新（可手动选择）
3. 点击安装——启动器会拉取 Fabric profile 并与原版版本合并，
   生成 `fabric-loader-<mc>-<loader>` 版本，出现在首页版本下拉中

## 7. 账户页

### 离线账户

- 输入玩家名添加；UUID 按 Minecraft 官方离线规则
  （`OfflinePlayer:<name>` 的 MD5 v3）生成，与正版/其他启动器互认
- 同名账户自动去重

### 微软正版账户（设备码登录）

1. 点击「微软登录」→ 显示设备码（如 `ABCD-EFGH`）与验证网址
2. 浏览器打开 `https://www.microsoft.com/link`，输入设备码并登录微软账户
3. 启动器自动完成登录（Xbox → Minecraft 换票）并添加账户、设为默认

登录使用 Minecraft 官方启动器的应用身份；令牌过期后需重新执行设备码登录。

### 默认账户 / 删除

- 每个账户行可「设为默认」；默认账户在首页直接生效
- 删除需二次确认（ContentDialog）

## 8. 设置页

分组卡片布局，修改后点击底部「保存设置」（成功弹出「已保存」提示）：

| 分组 | 项 |
| --- | --- |
| 游戏目录 | `.minecraft` 目录路径（版本/库/资源安装位置） |
| 内存分配 | 最小内存（默认 512 MB）/ 最大内存（默认 4096 MB） |
| Java | java.exe 路径（留空用系统 java）；「检测系统 Java」；「下载 Java 21 / Java 8（Temurin）」一键托管下载 |
| 下载与外观 | 下载并发数（1-64）；外观（跟随系统 / 浅色 / 深色） |

Java 托管下载位置：`%APPDATA%/starcloud-launcher/java/<主版本>/`。

## 9. 启动器日志页

- 只读显示启动器日志尾部（等宽字体），排查安装/启动问题用
- 日志文件位置：`%APPDATA%/starcloud-launcher/logs/`

## 10. 常见问题

| 现象 | 处理 |
| --- | --- |
| 启动游戏报「找不到 Java」 | 设置页 → 下载 Java 21（Temurin），或手动填入 java.exe 路径 |
| 下载速度慢 | 设置页提高「下载并发数」（默认 16） |
| 下载失败 | 网络问题自动重试；失败后 InfoBar 显示原因，可重试安装（已下载文件自动跳过） |
| 微软登录卡住 | 确认浏览器已完成设备码授权；令牌过期则重新登录 |
| Fabric 安装失败 | 先确认对应原版已安装（下载页） |
| 游戏启动即崩溃 | 查看游戏目录 `logs/latest.log` 与启动器日志页 |
| 界面颜色不对 | 设置页「外观」切回「跟随系统」 |

## 11. 数据位置

```
%APPDATA%/starcloud-launcher/   启动器数据（设置/账户/Java/日志）
%APPDATA%/.minecraft/           默认游戏目录（可在设置中修改）
```
