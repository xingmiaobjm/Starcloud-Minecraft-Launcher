# Starcloud Minecraft Launcher — 用户手册

> 版本 0.2.0 | 2026-08-09  
> 面向最终用户：安装、登录、版本管理、ModLoader、插件与常见问题。

---

## 1. 简介

Starcloud Minecraft Launcher 是一个开箱即用的 Minecraft 启动器，支持：

- 一键安装 Mojang 官方版本（正式版 / 快照 / 旧版）
- 正版（微软）与离线两种账户模式
- 为已安装的版本一键安装 Fabric 加载器
- GUI 插件扩展（视图插件 / 整体替换插件）

## 2. 安装与运行

### Windows

1. 从发布页下载安装包（`.exe`，NSIS 安装程序）并运行；
2. 按向导完成安装，桌面上出现启动器图标；
3. 双击启动。首次运行会在系统目录创建配置并显示主界面。

### macOS / Linux

- macOS：安装 `.dmg` 后拖入「应用程序」；
- Linux：安装 `.deb` / AppImage 后运行。需系统满足依赖（见 [README](../README.md)）。

## 3. 界面总览

启动器主界面由左侧导航与右侧内容区组成：

| 导航项 | 功能 |
|--------|------|
| 首页 | 选择版本与账户、调整启动模式、启动/停止游戏 |
| 版本 | 已安装版本管理（删除 / 安装 Fabric）、远程版本安装 |
| 账户 | 微软账户登录、离线账户管理、默认账户设置 |
| 插件 | GUI 插件安装 / 删除 / 启停、核心插件列表 |
| 设置 | 游戏目录、Java、内存、窗口与下载参数 |
| 日志 | 游戏实时日志与历史日志 |

> 安装了视图插件后，导航底部会出现「插件视图」区域，点击进入插件页面。

## 4. 快速开始

### 4.1 安装第一个版本

1. 进入「版本」页；
2. 在「远程安装」区域筛选或搜索版本号（如 `1.21.4`）；
3. 点击「安装」，底部状态栏显示安装进度（客户端 jar → 库文件 → 资源文件）；
4. 安装完成后，已安装列表出现该版本。

### 4.2 启动游戏

1. 回到「首页」，选择版本；
2. 选择账户模式与账户（详见第 5 节）；
3. 点击「启动游戏」。首次启动会检测 Java、补齐缺失文件，然后拉起游戏；
4. 游戏运行期间按钮变为「停止游戏」，点击可强制结束。

### 4.3 安装 Fabric 加载器

1. 在「版本」页的「已安装」列表，找到原版版本；
2. 点击其右侧「安装 Fabric」；
3. 等待完成。新版本形如 `fabric-loader-{版本号}-{MC版本}`，出现在已安装列表，可直接在首页选择启动。

> 安装 Fabric 后原版版本不会被删除，两者可并存。

## 5. 账户

### 5.1 离线账户

1. 进入「账户」页；
2. 在「离线账户」输入玩家名（≤16 字符），点击「添加」；
3. 可点击「设为默认」设为默认账户，或「删除」移除。

> 离线账户仅用于离线模式游玩，无法访问需要正版验证的服务器。

### 5.2 微软账户（正版）

1. 进入「账户」页，点击「微软登录」；
2. 页面显示一个 **8 位设备码** 与授权链接（也可点击「打开页面」）；
3. 在浏览器中打开链接，登录微软账号并输入设备码授权；
4. 页面自动轮询，成功后账户出现在列表中（登录凭证将自动续期，无需重复授权）。

> 提示：设备码有有效期（默认 15 分钟），过期后重新发起登录即可。

### 5.3 首页选择账户

首页顶部有「正版 / 离线」切换。切换到对应模式后，下拉框列出该模式下的账户；选择后会自动设为默认账户（`resolve_credentials` 使用默认账户凭据启动）。

## 6. 插件

### 6.1 安装插件

1. 进入「插件」页；
2. 填写插件包地址：
   - **URL**：网络地址（`https://…/my-plugin.zip`）
   - **本地路径**：本机 zip 文件路径
3. 点击「安装」。校验通过后插件出现在列表并自动启用。

> 插件包为 zip 格式，根级必须包含 `plugin.json`（详见 [插件开发指南](PLUGIN_DEV_GUIDE.md)）。

### 6.2 管理插件

| 操作 | 说明 |
|------|------|
| 禁用 / 启用 | 切换插件生效状态（禁用后从导航隐藏） |
| 删除 | 移除插件及文件 |

不兼容插件（API 版本或启动器版本不满足）会显示原因，无法启用。

> 替换（replacement）插件启用后将接管整个主界面；如需恢复默认界面，可在插件页将其禁用。

## 7. 设置

| 设置项 | 说明 |
|--------|------|
| 游戏目录 | `.minecraft` 位置（版本、库、资源、账户数据均存储于此） |
| 语言 | 界面语言（当前版本固定中文，字段保留） |
| 内存 | 最小 / 最大内存（MB），建议 ≥1024MB |
| 窗口 | 默认窗口宽高 |
| Java 路径 | 指定 Java 可执行文件（留空则自动检测系统 Java） |
| 附加 JVM 参数 | 追加到启动命令的自定义参数 |
| 下载并发 / 重试 | 下载并发数与失败重试次数 |

修改后点击「保存」，配置写入系统目录 `{config}/starcloud-launcher/config.toml`。

## 8. 日志

「日志」页显示游戏运行时的实时输出（订阅 `game-log` 事件），并支持查看历史日志（`.minecraft/logs/latest.log` 末尾 400 行）。启动失败时可在此查看崩溃信息。

## 9. 常见问题

**Q1：启动提示「未检测到系统 Java」？**
A：安装 Java 17+（推荐 [Adoptium](https://adoptium.net/)），或在「设置」中指定 Java 可执行文件路径。

**Q2：安装进度卡住 / 下载失败？**
A：网络问题可提高「设置」中的下载重试次数与并发数；确认磁盘空间充足（单个版本约 300MB–1GB）。

**Q3：微软登录轮询一直「等待授权」？**
A：确认已在浏览器完成授权且输入了正确的设备码；轮询过快会提示"轮询过于频繁"，稍候会自动继续。

**Q4：安装 Fabric 报「MC 版本没有可用的 Fabric 版本」？**
A：该 MC 版本可能过老或过新（Fabric 未跟进）。仅对官方支持的 MC 版本有效。

**Q5：启动后白屏 / 立即退出？**
A：查看「日志」页输出；常见原因为 Java 版本不符或显卡驱动问题。可将完整日志反馈给开发者。

## 10. 数据位置

| 数据 | 位置 |
|------|------|
| 启动器配置 | `{系统配置目录}/starcloud-launcher/config.toml` |
| 游戏数据（版本/库/资源） | 设置中的「游戏目录」（默认 `{数据目录}/.minecraft`） |
| 账户 | `{游戏目录}/accounts.json` |
| 插件 | 设置中的插件目录（环境变量 `STARCLOUD_PLUGINS_DIR` 可覆盖） |
