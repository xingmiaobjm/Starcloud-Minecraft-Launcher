# 待办：3D 预览不显示披风

状态：挂起（用户确认先保留，不阻塞其它工作）

## 现象
- 账号详情页（第三方 / LittleSkin 账户）的 3D 预览看不到披风。
- 衣柜里能列出披风、缩略图正常、点披风能成功换到角色（服务端已生效，状态行显示「已为角色「xia_l_x」换上这件披风。」）。
- 皮肤分类的 3D 预览正常。

## 已做的排查与改动（都已合入，2026-10-26）
1. `YggdrasilService.GetTexturesAsync` — 会话接口同时解出 `SKIN.url` 与 `CAPE.url`（原来只有 SKIN）。
2. `SkinFigureView` — 外部账户加载时把披风纹理一并下载缓存（缓存键含披风 URL 指纹，换披风自动失效），并把披风字节交给建模。
3. `SkinModel.CapeTexture` — 新增属性：此前构造时只拿披风建了几何 UV，纹理本身被丢弃，渲染器无从采样。
4. `SkinRenderer`（CPU 回退路径）— 面片按 `Part == "cape"` 分流，披风面片用披风纹理采样。
5. `SkinGpuRenderer`（GPU 主力路径）— 新增披风纹理三件套（`_capeTexture` / `_capeView` / 源指纹），顶点分两组绘制：身体用皮肤 SRV、披风切披风 SRV；`Dispose` 同步释放。
6. `CapeThumbImage` — HD 披风（128×64 / 512×256…）按宽度等比缩放裁剪区域，修「只显示一部分」。

## 下一步怀疑点（未验证）
- 披风 URL 可能取不到：`CAPE.url` 在 BS6 的会话纹理里未必是直链（可能是 `textures` 数组或需拼接站点根）。
- 缓存命中旧皮肤：`e_<server>_<uuid>.png` 与披风缓存是两个文件，换披风后皮肤缓存没失效，模型仍用旧纹理。
- `PlayerModel.BuildQuads` 可能没为 `cape` 生成面片（`Pose.CapeX` 存在但几何是否进 `Cubes` 未验证）。
- `Part` 名不是 `"cape"`：分流判断写死了字符串 `cape`，若模型里是别的名字就分流不到。
- 披风几何位置（`new Vec3(-5, 8, 2) → (5, 24, 3)`）可能被身体挡住，视觉上像"没有"。

## 复现路径
启动器 → 账户 → LittleSkin 账户 → 形象与皮肤 → 衣柜切「披风」→ 点一张披风 → 看左侧 3D 预览（需旋转到背面）。
