## 3. 制作要点

1. **文字纪律**：唯一允许的文字是 LOGO 与五个格式名；速度数字、六位联机码是数字不是文案。
2. **重拍=转场，留白=情绪**：11 / 24 / 26 镜的剪点必须卡在 32.5 / 80.5 / 90.0 的重击上（±1 帧）；
   57–64s 的留白段禁止任何 UI 镜头，只留世界。
3. **UI 动效实拍实录**：镜 2–10、12–16、19、22–25 直接录屏真实交互，不另做包装动画——动效本身就是卖点。
4. **世界镜头只有 4 个**（17 / 18 / 19 / 26），全在音乐变奏处，与 UI 快剪形成呼吸。
5. **落地必须是游戏内视角**（镜 26），不拍服务器列表点加入；镜 27 手离开键盘不加特效。
6. **首尾利用静默**：0–1.5s 与 102.5s 后音乐自己让位——镜 1 微光与镜 29 LOGO 不与任何节拍抢。
