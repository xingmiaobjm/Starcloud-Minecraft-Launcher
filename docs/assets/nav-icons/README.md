# 左侧导航图标（PNG，透明底）

从启动器的导航定义（`BuiltinShellPlugin.Entries`）导出，256×256、透明底。

| 目录 | 用途 |
| --- | --- |
| `black/` | 深色图标（#111111），用于浅色背景 |
| `white/` | 白色图标，用于深色背景 / 宣传片叠在画面上 |
| `color/` | Nova 品牌标记原色（黄底黑星，单色化会丢形状，只提供彩色版） |

| 文件 | 页面 | 来源 |
| --- | --- | --- |
| `home.png` | 首页 | 鸿蒙图标字体 U+EC77 |
| `versions.png` | 版本 | U+EA94 |
| `download.png` | 下载 | U+E90C |
| `saves.png` | 存档 | U+EA90 |
| `friends.png` | 好友 | U+EB91 |
| `lab.png` | 实验室 | `Assets/Brand/lab-nav.svg` |
| `projections.png` | 投影管理 | `Assets/Brand/projection-nav.svg` |
| `running.png` | 运行状态 | U+EC3B |
| `accounts.png` | 账户 | U+EB8F |
| `plugins.png` | 插件 | U+EABC |
| `ai.png` | Nova | `Assets/Brand/starcloud-mark-small.svg`（仅 `color/`） |
| `logs.png` | 启动器日志 | U+EC64 |
| `settings.png` | 设置 | U+EC04 |

`_preview.png` 是黑白两套的总览图（上排黑、下排白）。
